# MDPhy-web
Official company website for Practical MDPhy Tech, showcasing medical physics projects, software solutions, AI research, quality assurance, dosimetry, and educational resources.

The site uses `MDPhy Tech Healthcare Logo.png` for its favicon and brand marks.
The video-completion branding in `index.html` listens for the end of every
native HTML `<video>` element, including videos added dynamically, and displays
the logo animation for three seconds. The current learning-resource cards are
previews rather than video players; the branding is ready for players added to
the page.
