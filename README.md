# MDPhy-web
Official company website for Practical MDPhy Tech, showcasing medical physics projects, software solutions, AI research, quality assurance, dosimetry, and educational resources.

The site uses `MDPhy Tech Healthcare Logo.png` for its favicon and brand marks.
The homepage links to `resources.html`, which contains the available learning
videos. `video-end-screen.js` automatically displays the logo over any native
HTML `<video>` element for three seconds after playback ends; it is shared by
both pages and also handles videos added dynamically.
